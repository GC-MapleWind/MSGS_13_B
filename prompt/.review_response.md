## 🔒 Security Issues - Fixed

### 1. ✅ Dockerfile - Non-root User
**Issue**: 컨테이너가 root로 실행되는 보안 위험
**Fix**: 
- `appuser` 비root 유저 생성
- 애플리케이션 디렉토리 소유권 변경
- `USER appuser`로 전환하여 안전하게 실행

```dockerfile
RUN groupadd -r appuser && useradd -r -g appuser appuser
RUN chown -R appuser:appuser /app
USER appuser
```

### 2. ✅ Dockerfile - HEALTHCHECK Endpoint
**Issue**: `/api/v1/characters`는 DB 의존적인 비즈니스 엔드포인트
**Fix**:
- `/health` 전용 헬스체크 엔드포인트 추가 (main.py)
- HEALTHCHECK에서 `/health` 사용

```python
@app.get("/health")
async def health_check():
    """Health check endpoint for container orchestration."""
    return {"status": "healthy"}
```

### 3. ✅ GitHub Actions - SSH Security
**Issue**: `StrictHostKeyChecking=no`로 MITM 공격 위험
**Fix**:
- `ssh-keyscan`으로 호스트 키를 이미 추가하므로 `StrictHostKeyChecking=no` 제거
- 변수에 쿼팅 추가

```yaml
ssh -i ~/.ssh/deploy_key "${SERVER_USER}@${SERVER_HOST}" << ENDSSH
```

### 4. ✅ setup_server.sh - Shell Variable Quoting
**Issue**: 변수 미인용으로 인한 command injection 위험
**Fix**:
- 모든 변수에 쿼팅 추가: `"$REPO_URL"`, `"$DEPLOY_PATH"`
- `set -euo pipefail`로 엄격한 에러 처리

```bash
set -euo pipefail
git clone "$REPO_URL" "$DEPLOY_PATH"
cd "$DEPLOY_PATH"
```

## ⚙️ Configuration Issues - Fixed

### 5. ✅ GitHub Actions - DEPLOY_PATH Inconsistency
**Issue**: 문서는 `BACKEND_DEPLOY_PATH`인데 워크플로우는 `DEPLOY_PATH` 사용
**Fix**:
- 워크플로우를 `BACKEND_DEPLOY_PATH`로 통일
- 기본값을 `~/dpbr_backend`로 명확화

```yaml
DEPLOY_PATH: ${{ secrets.BACKEND_DEPLOY_PATH }}
cd ${DEPLOY_PATH:-~/dpbr_backend}
```

### 6. ✅ GitHub Actions - Heredoc Variable Expansion
**Issue**: `<< 'ENDSSH'` (quoted)로 인해 원격에서 변수 확장 안 됨
**Fix**:
- `<< ENDSSH` (unquoted)로 변경하여 변수 확장 허용
- GitHub Actions 변수는 `${{ }}` 구문으로 명확히 구분

```yaml
ssh -i ~/.ssh/deploy_key "${SERVER_USER}@${SERVER_HOST}" << ENDSSH
  cd ${DEPLOY_PATH:-~/dpbr_backend}
  # ...
ENDSSH
```

### 7. ✅ GitHub Actions - Health Check Error Handling
**Issue**: `|| echo` fallback으로 실패가 마스킹됨
**Fix**:
- `set -e` 추가
- 실패 시 명시적으로 `exit 1`
- 두 개의 헬스체크 (/health, /api/v1/characters) 모두 확인

```bash
curl -f "http://${SERVER_HOST}/health" || {
  echo "❌ Health check failed"
  exit 1
}
```

### 8. ✅ setup_server.sh - REPO_URL Placeholder
**Issue**: `YOUR_USERNAME` 플레이스홀더로 스크립트 실패
**Fix**:
- 실제 저장소 URL로 변경: `https://github.com/GC-MapleWind/MSGS_13_B.git`

```bash
REPO_URL=${REPO_URL:-"https://github.com/GC-MapleWind/MSGS_13_B.git"}
```

### 9. ✅ setup_server.sh - Systemd $HOME Paths
**Issue**: `$HOME` 확장이 스크립트 실행 시점에 발생하여 잘못된 경로 사용
**Fix**:
- `$HOME`을 `/home/${DEPLOY_USER}`로 explicit path 사용

```bash
Environment="PATH=/home/${DEPLOY_USER}/.cargo/bin:/usr/local/bin:/usr/bin:/bin"
ExecStart=/home/${DEPLOY_USER}/.cargo/bin/uv run uvicorn main:app --host 0.0.0.0 --port 8000
```

**Fix**:

```nginx
}

    expires 1y;
    add_header Cache-Control "public, immutable";
}
```
